# Tanish Kumar Portfolio

A static, responsive portfolio website based on Tanish Kumar's resume.

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize before publishing

Update the contact links in `index.html` if Tanish's LinkedIn and GitHub URLs become available. The project cards intentionally do not link to a live site because those URLs were not provided in the resume.
